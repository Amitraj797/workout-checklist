FEATURES (Same as V3 + New)

EXERCISE TRACKING:

TIMER:

  - Auto-starts after completing a set

  - 3-week cycle tracking

  - Purple left-border blocks grouping paired exercises
  - Only on isolation/accessory movements
  - Never on heavy compounds (bench, leg press, RDL, heavy rows)
  - Specific rest times per superset (45-60s between rounds)

TECHNIQUE TAGS:
  - RIR (Reps In Reserve) per set
  - FAILURE (go to failure on final set of isolation exercises)
  - SUPERSET (paired exercises)

EXPORT & RESET:

  - Export All History CSV - full cycle history
  - Export Weekly Log CSV - archived workout logs
  - Reset Day - clears one day (archives first)
  - Reset Week - clears all days (archives first)

BREATHING CUES:
  - Inhale/exhale instructions on every exercise

POST-WORKOUT CARDIO:
  - 15-20 min incline treadmill walk after every training day
